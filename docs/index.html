What survived scrutiny

The headline answer depends on workload. The formal campaign establishes short-context throughput; the fixed-context sweep exposes prefill and memory behavior; the latest continuous segment compares Uzu with the smaller VLM-MTP drafter.

Uzu leads overall

Uzu averaged 20.18 tok/s in the formal campaign. At 10k context it decoded 19% faster than OptiQ + DFlash by arithmetic mean and delivered roughly 2× end-to-end throughput.

Speculation helps oMLX—unevenly

Against the same target checkpoints, 4-bit DFlash improved OptiQ by 140%, repaired native MTP by 112%, and BF16 DFlash improved MXFP4 by 57%.

VLM MTP closes the decode gap

Across eight matched random contexts from 2.5k to 23.6k, Uzu averaged 17.37 tok/s and MXFP4 + VLM MTP averaged 16.29 tok/s—a 6.7% Uzu lead. VLM MTP's mean TTFT was 11.2% lower in those pairs.

Long context is a memory test

Under the no-swap fairness guard, Uzu stayed clean through 40k, MXFP4 + 4-bit DFlash through 30k, and OptiQ + DFlash through 10k. Prefill cost deteriorated before decode collapsed.

Method, briefly

This harness prioritizes comparable requests over vendor-default benchmarks. The repository contains the exact prompts, runner, curated measurements, and detailed limitations.

Same requestIdentical messages and exact output caps; greedy temperature 0, top-p 1, top-k 1, and thinking disabled.

No warm-cache advantageRequest, prefix, paged, SSD, and DFlash caches disabled. A shared 512-token kernel warmup is excluded from timing.

One model at a timeSingle request concurrency and one loaded target/drafter pair prevent cross-engine memory contention.

Memory guardThe active server is stopped below 12% free RAM or above 4 GiB campaign swap growth. Boundary attempts are not treated as successful measurements.

Honest efficiency labelsoMLX reports draft acceptance. Uzu reports target verification passes. Those counters explain behavior but are not presented as the same metric.

Known limitationUzu's bundled speculator cannot be disabled in the tested public CLI, so no within-Uzu speculative speedup is claimed.
